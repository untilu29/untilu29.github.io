# manhchuc.com assets

Font and images for www.manhchuc.com, served through jsDelivr at a tag of this repository.

- `fonts/inter-var-latin-vi.woff2`: Inter (SIL Open Font License, see `fonts/OFL.txt`) cut to Latin, Vietnamese and German
- `img/cv-photo.webp`, `img/avatar-128.webp`, `img/og-cv.jpg`: CV photo, small avatar and share image
